BirbCafe Admin Guide

Welcome to the official user guide for operating and managing BirbCafe.com! This document focuses on the administrative functions of your WooCommerce dashboard, providing detailed guidance for staff and owners.

Home: Administrative Dashboard Overview

The Dashboard provides a real-time summary of store health and quick access to administrative functions.

1. Daily Operational Snapshot (Your Store Today)

This section shows the number of critical items that need immediate attention from staff.

  • Orders: The number of orders that currently require processing, fulfillment, or review.
  • Stock: The number of products that are currently low or out of stock, requiring inventory review or restocking.

2. Performance Metrics (Stats Overview)

This panel summarizes key sales data, which can be filtered by Today, Week to date, or Month to date.

  • Total sales: The total revenue generated for the selected period.
  • Orders: The total count of orders placed for the selected period.
  • View detailed stats: A link below the metrics that redirects you to the comprehensive Analytics section for deeper reporting.
  • Note: The dashboard also shows percentage comparisons to the previous equivalent period.

3. Inbox Alerts

The Inbox provides real-time alerts for store activity, including new orders, reviews, and offers tips or specific news related to your WooCommerce installation.

4. Store Management Quick Links

This section contains links to crucial setup and management areas for the store.

Marketing & Merchandising

  • Marketing: Access a page where you can find extensions (add-ons) to enhance your store's marketing capabilities.
  • Add products: Quickly jump to the product creation screen to list new items.
  • Personalize my store: Allows for basic customizations of the store's appearance, though this feature may be bypassed or offer limited utility if you are using a detailed, custom theme.
  • View my store: Opens the public-facing store in a new tab to see what customers see.

Settings

  • Store details: Update your store's name, address, currency, and other general information.
  • Payments: Configure and manage the payment gateways (like PayPal or Stripe) your store accepts.
  • Tax: Set up and manage tax rates and options for different regions.
  • Shipping: Define shipping zones, methods, and costs for delivering products to customers.

Orders: Managing Orders

The Orders section is the main hub for processing, tracking, and completing customer purchases.

The Orders Screen Overview

This section lists all transactions and allows you to manage them efficiently.

  • Add order: Button at the top to manually create a new order (e.g., for phone orders). Note: This feature is currently not being used.
  • Order Status Filters: Quick-access tabs above the main list allow filtering by the current state of the order:
    • All (22): Shows every order.
    • Pending payment (3): The customer has initiated the order but payment has not been successfully received.
    • Completed (18): The order has been paid for and successfully delivered/fulfilled.
    • Failed (1): Payment failed or the order was cancelled by the system.
  • Search Orders: Use the search bar on the right to find specific orders by customer name, order number, or total amount.

Filtering and Sorting Orders

The row of dropdown menus helps you quickly refine the list to find specific sets of orders:

  • Bulk actions: Allows you to select multiple orders (using the checkboxes on the left) and apply status changes or management actions simultaneously. Common actions include:
    • Change status to processing/on-hold/completed/cancelled.
    • Move to Trash.
    • Send/Cancel Review Reminder. 
    • Click Apply after selecting an action.
  • Filter by date (All dates): Restrict the visible orders to a specific time range by selecting a date range from the dropdown.
  • Filter by shipping provider: Filter orders based on the carrier used. Available options include: DHL US, FedEx, UPS, USPS, and FedEx Ground.
  • Filter by order type (All orders types): This filter is essential for subscription stores and allows you to narrow results by transaction type, including:
    • Original: The initial purchase of a product or subscription.
    • Subscription Parent: The main, recurring order record.
    • Subscription Renewal: Automatic recurring charges for an active subscription.
    • Subscription Resubscribe/Switch: Orders generated when a customer restarts or changes their plan.
    • Non-subscription: Standard one-time purchases.
  • Filter by sales channel (All sales channels): Filter orders based on the specific origin of the purchase. The available options are:
    • Admin: Orders that were manually created by a staff member via the WooCommerce dashboard.
    • Checkout: Orders placed by a customer directly through the BirbCafe.com website.
    • Point of Sale: Orders processed using a dedicated retail system (if applicable).
  • Filter by registered customer: Filter to see orders only from customers who have created an account. This is useful for quickly identifying orders that may need manual customer service follow-up.
  • Sorting: You can sort the orders in ascending or descending order by clicking on the column headers for Order #, Date, and Total. An arrow will indicate the active sorting direction.

Detailed Order Edit Screen

Clicking the Order # link on the main table opens the detailed Order Edit screen, which is used for fulfillment, tracking, and management.

Order Information Area (Top Left)

This area summarizes the general and payment details for Order #11424 (using the sample image).

  • Order Header: Displays the unique Order # and the initial summary of the order placement time and customer IP.
  • General Panel: Contains core administrative details:
    • Date created: The exact date and time the order was placed.
    • Status: A dropdown menu allowing immediate status changes (e.g., from Processing to Completed).
    • Customer: Links to the customer's account profile and history.
  • CryptoPay Payment Details: This specific panel appears when payment is processed via CryptoPay and contains transaction metadata:
    • Blockchain Network: The network used for the transaction (e.g., Base).
    • Payment Amount: The exact amount paid in the cryptocurrency's unit (e.g., BIRB).
    • Transaction Hash: The unique on-chain identifier for the transaction.

Billing and Shipping (Center Columns)

This area contains the customer's contact and address information:

  • Billing: The name, address, and contact information (email, phone) used for payment.
  • Shipping: The name, address, and contact information used for delivery.

Order Item Breakdown (Bottom Center)

This table lists all products purchased, shipping details, applied coupons, and the final cost breakdown:

  • Item: Lists the product name, SKU, price, and quantity ordered.
  • Shipping: Displays the shipping option chosen by the customer (e.g., UPS Ground), along with any internal service information and the cost paid by the customer for delivery (e.g., $13.95).
  • Coupons: Any discount codes or gift certificates applied to the order (e.g., bd71b0ss).
  • Order Totals: A breakdown of the cost: Items Subtotal, Coupon(s), Shipping, Order Total, and the amount Paid.

Side Panel Management (Right Column)

This panel contains actions and supplementary data related to the customer and fulfillment:

  • Order Actions: A dropdown to perform administrative actions such as:
    • Change status: Quickly set the order status (same as the main Status dropdown).
    • Email invoice/details: Manually send the order confirmation or invoice to the customer.
    • Move to trash: Remove the order from the active list.
    • Click Update after selecting an action.
  • Order Attribution: Shows the customer's origin (e.g., Direct) and device type (e.g., Mobile).
  • Customer History: Shows the total orders, total revenue, and average order value for this specific customer.
  • Shipment Tracking: Allows staff to Add Tracking Info by selecting a carrier (e.g., UPS Ground) and entering the tracking number. This is essential for communicating delivery details to the customer.
  • Affiliate Commission: Allows staff to select which affiliate (if any) should receive commission for this specific sale.
  • Order Notes: This dynamic section tracks the entire history of the order and allows staff to add communication.
    • System Notes: Automatic entries show internal changes (e.g., status updates, payment confirmations, stock changes, shipping label creation). These notes are for informational purposes and cannot be edited.
    • Private Notes (Internal Staff Only): These notes are visible only to store staff and are used for internal communication, reminders, or special instructions (e.g., "Customer called to confirm address"). To add a private note, type your comment in the Add note field, select Private note from the dropdown, and click Add.
    • Customer Notes: These notes are either left by the customer during checkout or are visible to the customer (if chosen by staff). They represent communication that the customer can see.

Managing Products

This section covers the management of all products, including viewing the product catalog, editing stock, and accessing individual product details.

Products List Overview

The main Products screen lists all items available in the store, providing administrative tools for bulk management and filtering.

❗ Recommended Action: Streamlining Table View To focus on the most crucial product data and simplify the table for daily management, it is recommended to use the Screen Options menu (top right) to deselect unnecessary columns for a cleaner view. See the screenshot below for the optimal view.

  • Management Buttons (Top Left):
    • Add new product: Used to manually create and publish a new product listing.
    • Import: Used to bulk upload product data (e.g., via a CSV file) from an external source or spreadsheet.
    • Export: Used to download your current product catalog (e.g., for backup or migration).
  • Status Filters: Tabs above the product list allow filtering by the product's visibility status:
    • All: Shows all products.
    • Published: Products currently visible on the live storefront.
    • Private: Products only visible to logged-in users with appropriate permissions.
    • Sorting: Provides options to change the default sort order.
  • Bulk Actions: A dropdown menu allowing multiple selected products to be edited simultaneously. The two important actions are:
    • Edit (Bulk Edit)
    • Move to Trash
  • Filters: Dropdown menus allow filtering the list based on specific criteria:
    • Filter by Product Type: Filters by item category (e.g., Simple Product, Variable Product, Subscription).
    • Filter by Category: Filters by product category (e.g., Single Origin, Decaf).
    • Filter by Stock Status: Filters by current stock level (e.g., In stock, Out of stock, On backorder).
    • Filter by Brand: Filters products by their assigned brand. Not used on BirbCafe since all products are BirbCafe.
  • Product List Columns: The table displays key information for each product:
    • Thumbnail: Small image preview of the product.
    • Name: The product title. Clicking the name leads to the detailed Product Edit Screen.
    • SKU: The unique product identifier.
    • Stock: The current inventory level and status (e.g., 5 in stock, Out of stock).
    • Price: The item's retail price (may show a range for variable products).
    • Categories: The product taxonomy tags assigned.
    • Featured: Indication if the product is marked as featured (e.g., with a star icon).
    • Date: The date the product was last modified or published.
  • Quick Actions (on Hover): Hovering over a product name reveals links for quick management: Edit | Quick Edit | Trash | View | Clear this cache (WP Rocket/Caching) | Duplicate.

Product Edit Screen Overview

The main Edit Product screen is where all specific product details, including pricing, inventory, descriptions, and metadata, are managed.

  • Product Name: The main input field for the product's title.
  • Product Description: The primary visual/code editor used for the full, detailed product description displayed on the main product page.
  • Product Data: A tabbed section used to configure the core e-commerce aspects of the product. View Product Data below.

Side Panel Elements (Right Column, Top to Bottom)

  • Publish Box: Controls the product's visibility status and publication schedule:
    • Status: Dropdown to set visibility (Published, Draft, Private).
    • Visibility: Link to set catalog and search visibility (e.g., Public, Password protected).
    • Publish Date: Option to set a future date for automatic publication.
    • Update / Publish: Button to save changes or make the product live.
  • Product Image Box: Used to set the primary feature image displayed on the product page and in category listings.
  • Product Gallery Box: Used to add supplementary images (secondary product views, lifestyle shots, etc.).
  • Product Categories Box: Displays a list of all defined categories (e.g., All Coffee, Decaf, Single Origin) and allows selection.
  • Reviews Box: Displays comments and ratings specific to this product.
  • Product Short Description Box: A smaller editor for the brief summary often displayed next to the product price or image on the main product page.

Products: Add New Product

Similar to editing a product, this section describes the layout and key fields visible when creating a brand new product using the "Add new product" button.

  • Product Name: The main input field for the product's title.
  • Product Description: The primary visual/code editor used for the full, detailed product description displayed on the main product page.
  • Product Data: A tabbed section used to configure the core e-commerce aspects of the product (details start below in Product Data: General Tab).

Side Panel Elements (Right Column, Top to Bottom)

  • Publish Box: Controls the product's visibility status and publication schedule:
    • Status: Dropdown to set visibility (e.g., Draft is default).
    • Visibility: Link to set catalog and search visibility (e.g., Public).
    • Publish Date: Option to set a future date for automatic publication.
    • Publish: Button to save changes and make the product live.
  • Product Image Box: Used to set the primary feature image.
  • Product Gallery Box: Used to add supplementary images.
  • Product Categories Box: Displays a list of all defined categories and allows selection.
  • Reviews Box: Displays controls for enabling/disabling product reviews (if enabled via Screen Options).
  • Product Short Description Box: A smaller editor for the brief product summary.

Product Data: General Tab

The General tab, the first tab within the Product Data (Meta Box), controls basic pricing and tax information.

  • Product Type: Dropdown at the top of the Product Data box to select the product configuration (e.g., Simple product, Variable product).
  • Virtual: Checkbox to mark the product as virtual (no shipping required).
  • Downloadable: Checkbox to mark the product as downloadable (digital goods).
  • Regular price ($): Input field for the standard price of the product.
  • Sale price ($): Input field for a reduced promotional price. A Schedule link allows setting a start and end date for the sale price.
  • Tax status: Dropdown to determine if the product is Taxable, Shipping only, or None.
  • Tax class: Dropdown to select the applicable tax rate class (e.g., Standard, Zero Rate).
  • Stripe Tax - Product tax code: Dropdown to select the specific Stripe Tax code for accurate tax calculation.
  • Fixed price for each currency: This section allows manually setting fixed prices in specific currencies (USD, GBP, EUR, etc.). Note: This feature is only available in a professional version of the multi-currency plugin.

Product Data: Inventory Tab

The Inventory tab controls stock management settings, including SKU, stock quantity, backorders, and low stock thresholds.

  • SKU: Input field for the product's Stock Keeping Unit, a unique identifier.
  • GTIN, UPC, EAN, or ISBN: Input field for global trade item numbers (if applicable).
  • Stock management:
    • Track stock quantity for this product: Checkbox to enable WooCommerce to manage the stock level automatically. If unchecked, the product is assumed to be infinitely in stock.
    • Quantity: Input field for the current number of items in stock (visible only if 'Track stock quantity' is checked).
  • Allow backorders?: Radio buttons to determine behavior when stock reaches zero:
    • Do not allow
    • Allow, but notify customer
    • Allow
  • Low stock threshold: Dropdown/input field to set the stock quantity that triggers a low stock email notification (e.g., Store-wide threshold (2)).
  • Sold individually: Checkbox to limit purchases of this item to 1 per order.
  • Backorders: Read-only field displaying the number of backordered items (visible only if backorders are allowed).

Product Data: Shipping Tab

The Shipping tab controls the physical dimensions and weight of the product, which is critical for calculating dynamic shipping rates.

  • Weight (lbs): Input field for the product's weight in pounds (or the configured unit).
  • Dimensions (in): Input fields for the product's dimensions: Length, Width, and Height in inches (or the configured unit).
  • Shipping class: Dropdown to assign a specific shipping class (e.g., "No shipping class," "Fragile," "Heavy Item"). Shipping classes are used to group similar products for complex shipping rule creation.

Product Data: Linked Products Tab

The Linked Products tab is used to create specific product recommendations for the customer journey, including upsells and cross-sells.

  • Upsells: Search field used to select products displayed on the current product's page, encouraging customers to purchase a more expensive or higher-margin product than the one they are viewing.
  • Cross-sells: Search field used to select products displayed in the customer's cart, encouraging them to buy related or complementary items before checkout.
  • Save Changes: Changes made within the Product Data tabs are saved when the main Update/Publish button is clicked.

Product Data: Attributes Tab

The Attributes tab allows staff to define descriptive information about a product that can be displayed on the storefront or used for product variations (if the product type is "Variable product").

  • Attribute Management:
    • Add new: Button to create a new custom attribute specific to this product (e.g., "Roast Level").
    • Add existing: Dropdown to select a pre-defined global attribute (e.g., Color, Size) that has been configured for the entire store.
  • New Attribute Setup (when adding a new attribute):
    • Name: Input field for the name of the attribute (e.g., length or weight).
    • Value(s): Textarea input for listing the descriptive terms (values) for the attribute. Values must be separated by the pipe symbol (|).
    • Visible on the product page: Checkbox to control whether this attribute is displayed under the "Additional information" tab on the product's storefront page.
    • Save attributes: Button to save the current attribute configuration.

Product Data: Advanced Tab

The Advanced tab controls options for adding an optional purchase note, setting the menu order for the product, and enabling/disabling customer reviews.

  • Purchase note: Textarea field for a custom message sent to the customer after purchasing this product.
  • Menu order: Input field to set a numerical order for displaying this product in lists (lower numbers display first).
  • Enable reviews: Checkbox to allow customers to leave reviews and ratings for this product.

Product Data: Stripe Settings Tab

The Stripe Settings tab is where staff can manage which specific Stripe-related payment methods (like "Buy Now" buttons, wallets, and "pay later" options) are displayed for this individual product.

  • Method List: A table showing the various Stripe payment methods (e.g., Link Checkout, Klarna, Google Pay, Apple Pay, etc.) with controls for each:
    • Method: The name of the payment gateway option.
    • Enabled: A toggle switch to quickly enable or disable the method for this product.
    • Charge Type: A dropdown to select the charge action, usually Capture (charge immediately) or Authorize(hold funds).
  • Button Position: A dropdown to select where the express checkout buttons (like Apple Pay or Google Pay) should appear on the product page (e.g., Below add to cart).
  • Save: Button to save the current Stripe payment method configuration for this product.

Product Data: AffiliateWP Tab

The AffiliateWP tab is used to override the global affiliate commission rates and rules for this specific product.

  • Affiliate Rate Type: Dropdown to select the type of commission rate that applies to this product's sale: Site Default, Percentage (%), or Flat USD.
  • Affiliate Rate: Input field to set the specific commission value. This value is used instead of the global default rate set in the AffiliateWP settings.
  • Disable referrals: Checkbox to prevent this product from generating referral commissions for affiliates entirely.

Product Data: Subscriptions Tab

The Subscriptions tab controls how this product functions as a subscription, allowing configuration of renewal settings or linking it to existing plans.

  • Sell on subscription? Dropdown to select the subscription model: Use global subscription plans (default), Allow one-time purchase, or Use product subscription plans.
  • Subscription Plan Settings: If custom product subscription plans is selected, this area allows defining the billing interval, trial period, and sign-up fees.
  • Global subscription plan settings: Link to view and edit global subscription settings.
  • Save Changes: Changes made within the Product Data tabs are saved when the main Update/Publish button is clicked.

Product Data: Get More Options Tab

The "Get More Options" tab provides a list of recommended extensions and add-ons from WooCommerce that can be integrated to enhance the functionality of the product. This tab is primarily promotional and informational, directing users to relevant external plugins.

  • Recommended Extensions (Visible List):
    • Composite Products: Create product kit and custom product configurators.
    • Product Bundles: Offers personalized product bundles, bulk discount packages, and assembled products.
    • WooCommerce Bookings: Allows customers to book appointments, make reservations, or rent equipment.
    • Invoice Payment Option: Allows customers to select the invoice payment option during checkout.
    • Product Add-Ons: Offers add-ons like gift wrapping, special messages or other special options for your products.
  • Save Changes: Changes made within the Product Data tabs are saved when the main Update/Publish button is clicked.

📈 Analytics: Analyzing Store Performance

The Analytics section provides comprehensive data reporting on various aspects of store performance, allowing administrators to track sales, revenue, products, and customer behavior.

Analytics Navigation and Filtering

The analytics reports are structured into several key areas, allowing for granular review of specific metrics.

  • Date Range Selector: Located at the top, this allows you to specify the time frame for the report. The options available in the dropdown include:
    • Presets: Today, Week to date, Month to date, Quarter to date, and Year to date.
    • Custom: Yesterday, Last week, Last month, Last quarter, and Last year.
  • Comparison Tool: This option, located below the date presets, allows you to compare the currently viewed period's data against a previous period to identify trends. Options include Previous period and Previous year.

Overview Report

The Overview is the default view, summarizing key performance indicators (KPIs) and providing visual charts and leaderboards for immediate insights.

Performance Section (KPI Boxes)

The Performance row is a customizable dashboard of your key sales figures. You can customize which metrics are visible using the "Display stats" option (three dots icon).

By clicking the 3 dots on the right side you can modify the view. Below are the different available sections you can show.

Charts: Performance Charts

The Charts section provides a visual representation of key trends over the selected date range.

  • Chart Type Selector (By day / By week / By month): Located above the charts on the right, this dropdown controls the time grouping (or granularity) of the data points shown on the graph.
  • Net Sales Chart: Tracks the store's core revenue (Net Sales) over time. This helps visualize high-performing days or weeks and identify seasonality. The chart explicitly shows the current period's performance against the previous period's performance (if comparison is selected).
  • Orders Chart: Tracks the volume of orders placed over time. This helps correlate traffic or promotional events with customer buying activity. Like the Sales chart, it visually compares the current period against the previous one.
  • Chart Options: The three-dots icon above the charts allows you to select which metric is being plotted (e.g., switch from Net Sales to Orders).

Leaderboards

The Leaderboards section shows the top-performing categories and products for the selected date range, aiding in merchandising and purchasing decisions.

  • Top Categories - Items Sold: Lists categories ordered by the volume of items sold within each. This table includes the Category name, the number of Items sold, and the resulting Net sales.
  • Top Products - Items Sold: Lists individual products ordered by the volume of items sold, providing granular insight into customer demand. This table includes the Product name, the number of Items sold, and the resulting Net sales.

Filtering Products

In addition to the standard Date Range Selector, the Products report allows specialized filtering:

  • Filter by Product: A dropdown that lets you view data for All products or narrow the report to a Single product(or a custom selection).

Revenue (Analytics)

The Revenue report provides a deep dive into the financial performance of the store, breaking down total sales into its constituent parts.

Performance Metrics

This view focuses its KPI boxes on the core financial metrics:

  • Gross Sales: Total revenue before discounts, returns, and taxes are applied.
  • Returns: The total value of refunds issued to customers.
  • Net Sales: Gross sales minus returns and discounts (the true measure of revenue).
  • Taxes: The total amount of tax collected on both items and shipping.
  • Shipping: The total amount of revenue collected from shipping fees.

Revenue Breakdown Table

This table provides a summary of net revenue over the selected period, broken down by various dimensions (such as day, week, or month, depending on the chart selector).

Chart Options

The chart in the Revenue report primarily displays Net Sales and can be customized to show other metrics like Gross Sales or Returns over time. This helps visualize revenue fluctuations and the impact of returns/discounts.

Orders (Analytics)

The Orders report provides detailed data on the volume, status, and processing of customer transactions over time.

Performance Metrics

This view focuses its KPI boxes on transaction volume and fulfillment:

  • Orders: Total number of orders placed in the selected period.
  • Average Order Value (AOV): The mean value of all orders.
  • Net Sales: The net revenue generated, for context.
  • Total Tax: The total tax collected on all orders.
  • Internal Refunds: The total value of refunds processed through the store.
  • Average Items Per Order: The mean number of product line items within each order.

Orders Breakdown Table

Filtering Orders

    • Items sold (for variations)

The Coupons report tracks the effectiveness and usage of discount codes.

  • Commissions: Fine-tuning commission calculations (e.g., recurring commissions, tax handling).
  • Integrations: Connecting AffiliateWP to other services (e.g., WooCommerce, specific payment gateways).
  • Opt-In Form: Customizing fields for lead generation campaigns.
  • Emails: Configuring the content and recipients of all transactional emails (e.g., registration, approval, rejection).
  • Advanced: Technical settings like referral tracking method and exclusion rules.
  • Coupons: Managing the dynamic coupon creation feature.
  • Custom Affiliate Slugs: Configuring URL parameter options.

2. General Tab Details

The General tab is primarily used for activating and configuring the plugin license and running the setup wizard.

  • License Key: Field to enter the product license key. An active license enables automatic plugin updates and support access.
    • Action: Click Activate License after entry.
  • Setup Wizard: A button to launch the guided configuration wizard to quickly set up the basic parameters of the affiliate program.
  • Save Changes: Main button at the bottom to commit any modifications made on this tab.

3. Affiliates Tab Details

The Affiliates tab is used to control global referral rates, affiliate registration permissions, and tracking behavior.

  • Registration & Management (Top Section): Settings that govern affiliate accounts:
    • Affiliate Account Page: Dropdown to select the primary page where affiliates log in and access their data.
    • Affiliate Login Page: Dropdown to select the page where affiliates log into their account.
    • Affiliate Registration Page: Dropdown to select the page hosting the registration form.
    • Terms of Use Page: Dropdown to select a WordPress page containing the legal terms for the affiliate program.
    • Allow Affiliate Registration: Toggle to enable or disable new affiliate signups entirely.
    • Require Approval: Toggle to set new affiliate registrations to "Pending" status for manual review (versus auto-approving).
  • AI Review Instructions: A textarea field to provide custom instructions for an optional, external AI tool used for reviewing affiliate applications.
  • Starting Affiliate ID: Input field to set the numerical ID that new affiliate registrations will start from (always higher than the most recent ID).
  • Recaptcha Type: Dropdown to select the type of Google reCAPTCHA used for registration form spam prevention (options include None, reCAPTCHA v2, reCAPTCHA v3).
  • reCAPTCHA Site Key / Secret Key: Fields for entering the public and private keys from Google required to enable reCAPTCHA spam protection.
  • reCAPTCHA Threshold: Input field for setting the sensitivity score threshold for reCAPTCHA v3.
  • Additional Registration Modes: Radio buttons for optional methods of registering affiliates, which can be used alongside the standard form:
    • None: Disables additional registration methods.
    • Automatically register new user accounts as affiliates: Automatically promotes any new WordPress user to affiliate status.
    • Convert customers into affiliates using the affiliate signup widget: Allows customers to easily become affiliates after purchasing.
  • Affiliate Links: Settings for how affiliate links are generated and tracked:
    • Referral Variable: Input field for the URL variable used to track referrals (e.g., ref).
    • Default Referral Format: Dropdown to choose the structure of the referral URL (e.g., Custom Affiliate Slug, Default, Pretty Referrals).
    • Pretty Affiliate URLs: Checkbox to show pretty affiliate referral URLs (e.g., site.com/ref/username) instead of standard URL parameters.
  • Affiliate Link Sharing: Checkboxes to enable sharing links on various social media platforms directly from the Affiliate Area:
    • Facebook
    • LinkedIn
    • X (Formerly Twitter)
    • Email
    • QR Code
  • Affiliate UI (User Interface):
    • Logout Link: Checkbox to enable the display of a logout link in both the Affiliate Area and the Affiliate Portal.
  • Affiliate Landing Pages:
    • Landing Pages: Checkbox to enable the ability for affiliates to define custom landing pages.
  • Direct Link Tracking:
    • Allow direct link tracking: Toggle to enable the system to automatically track referrals based on the affiliate's website URL, even if the visitor removes the referral tag. This requires manual administrative approval of the affiliate's domain URL.

4. Commissions Tab Details

The Commissions tab is used to define global commission rules, calculate deductions, and manage payment logic.

  • Default Commission Settings:
    • Referral Rate Type: Radio buttons to set the default rate type for all commissions: Percentage (%) or Flat USD.
    • Referral Rate: Input field to set the global default commission value (e.g., 10 for 10% or 10.00 for $10).
    • Cookie Expiration: Input field to determine how many days the referral tracking cookie remains active (e.g., 300 days).
    • Credit Last Affiliate: Checkbox to ensure commissions are credited to the last affiliate link clicked by the customer before purchase (Last Click Attribution).
    • Exclude Shipping: Checkbox to exclude shipping costs from the referral calculation basis.
    • Exclude Tax: Checkbox to exclude tax from the referral calculation basis.
    • Reject Unpaid Referrals on Refund: Checkbox to automatically reject any outstanding (unpaid) commission when the associated purchase order is refunded.
    • Ignore Referrals with Zero Amount: Checkbox to prevent commissions of $0.00 from being recorded in the system.
    • Commission Holding Period: Input field to specify the number of days commissions should remain in a "Pending" or "Unpaid" status before being available for payout.
  • Payout Methods: Radio buttons to select the system used for processing payments:
    • Payouts Service: Uses the integrated AffiliateWP Payouts Service.
    • PayPal Payouts: Uses the linked PayPal Payouts payment method.
    • Manual Payout: Payments are processed manually (e.g., bank transfer, cash, etc.).
  • Recurring Referrals:
    • Enable Recurring Referrals: Checkbox to enable automatic commission tracking for subscription renewals and recurring payments.
  • Multi-Tier Commissions:
    • Multi-Tier Commissions: Checkbox to enable multi-level commission structures for affiliates.
  • Multi-Currency:
    • Enable Multi-Currency: Checkbox to allow referral amounts to be recorded and displayed in multiple currencies.

5. Integrations Tab Details

The Integrations tab is where you enable AffiliateWP to connect and track referrals from supported e-commerce, forms, and membership plugins used on the BirbCafe.com site.

  • Integrations: A comprehensive list of compatible platforms where AffiliateWP can track referrals. Check the box next to the service to enable tracking. Currently configured options include:
    • Contact Form 7
    • Easy Digital Downloads
    • Elementor
    • Formidable Pro
    • Give
    • Gravity Forms
    • LearnDash
    • LifterLMS
    • MemberMouse
    • MemberPress
    • Ninja Forms
    • PayPal Buttons
    • Paid Memberships Pro
    • Paid Member Subscriptions
    • Restrict Content Pro
    • Sprout Invoices
    • WP Simple Pay
    • WooCommerce (Currently checked)
    • WP EasyCart
    • WPForms
  • Disable Referrals on Subscription Switch: Checkbox to prevent referrals from being created when customers change their existing subscriptions (using the Woo Subscriptions plugin). This prevents duplicate commissions on non-new sales.
  • Save Changes: Button to commit any modifications made on this tab.

6. Opt-In Form Tab Details

The Opt-In Form tab is used to configure settings specifically related to the affiliate signup widget, which allows users to subscribe to affiliate emails or offers.

  • Opt-in Referral Amount: Input field to enter the amount affiliates should receive for each successful opt-in referral. Default is set to 0.
  • Opt-in Referral Status: Radio buttons to select the default status for new opt-in referrals:
    • Pending
    • Unpaid
  • Message shown upon opt-in success: A visual/code editor field used to customize the message displayed to subscribers after they have successfully opted in.
  • Platform: A dropdown menu used to select the opt-in platform provider (e.g., Mailchimp, ConvertKit, etc.) you wish to integrate. Selecting a platform will reveal specific API fields for that service below the dropdown.
  • Save Changes: Button to commit any modifications made on this tab.

7. Emails Tab Details

The Emails tab is where all automated email notifications related to the affiliate system are configured and customized.

  • Email Options (Top Section): Controls the overall styling and basic sender information:
    • Logo: Field to upload a logo for display at the top of the email templates.
    • Email Template: Dropdown to choose a base template for email notifications (Default Template is the primary choice).
    • From Name: Input field for the name that appears as the sender (e.g., "BirbCafe Organic Coffee").
    • From Email: Input field for the email address used as the sender.
  • Email Notifications: Checkboxes to select which events trigger automated notifications:
    • Notify if affiliate manager gets a new affiliate registered
    • Notify if new message of opt-in referral is created
    • Notify if status message of referral changes
    • Notify if referral status changes to accepted
    • Notify if affiliate manager receives new opt-in referral
    • Notify if new affiliate application is pending
    • Notify if affiliate registration is approved
    • Notify if affiliate registration is rejected
    • The email notifications sent to the affiliate manager and affiliates. (This is a description, not a field).
  • Affiliate Email Summaries: Checkbox to enable sending regular email summaries of affiliate activity.
  • Affiliate Manager Email: Input field for the email address(es) that receive affiliate manager notifications (e.g., new applications).
  • Registration Email Options For Affiliate Manager: This section is an HTML/Visual editor used to customize the email sent to the manager when a new affiliate registers.
    • Registration Email Subject: Input field for the subject line (e.g., "New Affiliate Register on Your Site").
    • Registration Email Content: The main editor for the email body. This content uses template tags (e.g., {name}, {site_name}) which are listed below the editor for customization.
  • This section allows you to edit all emails used by the affiliate system.
  • Save Changes: Main button at the bottom to commit any modifications made on this tab.

8. Advanced Tab Details

The Advanced tab is used to configure technical settings related to currency, tracking, security, and data management.

  • Currency Settings:
    • Currency: Dropdown to select the primary currency used for commissions (e.g., US Dollar - USD).
    • Currency Symbol Position: Dropdown to choose the placement of the currency symbol (e.g., Before amount, After amount).
    • Thousands Separator: Input field for the character used to separate thousands (e.g., comma ,).
    • Decimal Separator: Input field for the character used to denote decimal points (e.g., period .).
    • Decimal Separator: Input field for the character used to denote decimal points (e.g., period .).
    • Decimals: Input field for the number of digits shown after the decimal point (e.g., 2).
  • Tracking: Settings related to the core referral tracking function:
    • Referral Tracking Method: Dropdown to specify how referrals are tracked (e.g., Cookies, Query Variables, Session).
    • Exclude URL: Textarea field where you can list specific URLs or paths that should be excluded from affiliate tracking.
    • Exclude Referrers: Textarea field where you can list specific domains/websites that should be excluded as referring sources.
  • Template File / Shortcode Settings:
    • Terms of Use Label: Text field for the label displayed next to the Terms of Use link on the registration form.
    • Affiliate Area & Pages: Dropdown to select who can view affiliate-related pages (e.g., All Non-Registered Users, Logged-in Affiliates).
    • Required Registration Fields: Checkboxes to select which fields are mandatory during affiliate registration (e.g., Name, Phone).
  • Email Summaries:
    • Disable Email Summaries: Checkbox to disable the optional email summaries of affiliate activity.
  • Privacy & Logging: Settings to manage security and user data retention:
    • Disable IP Address Logging: Checkbox to stop recording the IP address of visitors who click referral links.
    • Disable Logging of Usernames/Emails: Checkbox to stop logging the username and email of affiliates.
  • Data Management:
    • Referral Deletion Schedule: Dropdown to select a schedule for automatically deleting old referral data (e.g., Monthly, Quarterly).
  • Troubleshooting:
    • Use Legacy Referral Tracking: Checkbox to enable the older referral tracking system for compatibility purposes.
  • Save Changes: Main button at the bottom to commit any modifications made on this tab.

9. Coupons Tab Details

The Coupons tab is used to configure the dynamic creation and management of affiliate coupons.

  • Coupons:
    • Coupon Template: Dropdown field to select the WooCommerce coupon template that all dynamically created affiliate coupons will inherit their settings from (e.g., discount type, expiration).
    • Automatically Generate Coupons: Checkbox to automatically generate a coupon code for each registered affiliate.
      • Note: To bulk generate coupons for existing affiliates, you must visit the Tools screen.
  • Dynamic Coupon Customization:
    • Coupon Format: Dropdown to select a pre-defined format for dynamically generated coupon slugs (e.g., {coupon_code}).
    • Custom Text: Text input field to use within the {custom_text} merge tag of the Coupon Format option.
    • Hyphen Delimiter: Checkbox to add a hyphen between each merge tag in the coupon slug (e.g., user-code-custom).
  • Affiliate Link Discounts:
    • Enable Affiliate Link Discounts: Checkbox to instantly apply discounts for customers using affiliate links, bypassing the need for the customer to manually enter a coupon code.
  • Save Changes: Main button at the bottom to commit any modifications made on this tab.

10. Custom Affiliate Slugs Tab Details

The Custom Affiliate Slugs tab is used to configure the appearance and rules for affiliate slugs in referral URLs.

  • Allow Custom Affiliate Slugs: Checkbox to allow all affiliates to create a custom slug (e.g., /ref/my-custom-name). Leaving this unchecked will only enable custom slugs on a per-affiliate basis if granted individually.
  • Show Custom Slug: Checkbox to show the affiliate's custom slug in the Affiliate URLs tab of the Affiliate Area. This option is only effective if the affiliate has a custom slug and the Default Referral Format is set to ID or Username.
  • Auto-create Custom Slugs: Checkbox to enable the automatic creation of custom slugs for affiliates when they register or when affiliates are added manually.
  • Save Changes: Main button at the bottom to commit any modifications made on this tab.
