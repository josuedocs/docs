BirbTV Admin Guide

BirbTV Admin Documentation

Welcome to the official documentation for the BirbTV Admin Dashboard. This guide provides a detailed walkthrough of the interface, metrics, and management tools available to platform administrators.

1. Main Dashboard

The Main Dashboard provides a real-time snapshot of the platform's health and activity.

Dashboard Metric Tiles

The top section features 12 key metric tiles, displayed in the following order:

  • Total Videos: The cumulative count of all video files uploaded across the entire platform.
  • Total Channels: The number of unique creator or brand channels registered.
  • Total Playlists: The sum of all user-curated and system-generated video collections.
  • Total Users: The aggregate number of registered accounts on the site.
  • Total Blogs: The count of all published articles and text-based posts.
  • Total Advertisements: The number of active ad campaigns currently configured in the system.
  • Total Reports: A critical moderation metric showing the number of items flagged by users for review.
  • Active Member Subscriptions: The number of users currently on a paid or premium membership tier.
  • Total Comments: The total volume of discussion entries across all content types.
  • Total Likes: The total number of positive interactions recorded across the platform.
  • Total Dislikes: The total number of negative interactions recorded across the platform.
  • Total Favourites: The number of times content has been saved to user "Favorite" lists.

Analytics Charts

The middle section visualizes growth trends over the current calendar year (January through December).

  1. User Stats: A bar chart tracking new user registrations per month.
  2. Video Stats: A chart monitoring the volume of new video uploads per month.
  3. Channel Stats: A visualization of the rate at which new creator channels are being established.
  4. Blogs Stats: A graph tracking the monthly output of blog posts and written updates.

Latest Members

Located at the bottom of the dashboard, this section provides a horizontal feed of the most recent registrations.

  • User Avatar & Username: Quickly identify new users.
  • Join Date: Shows recency (e.g., "3 months ago").
  • View All Users: A quick link to access the comprehensive member management database.

2. Settings (settings)

This section contains the core configuration for the BirbTV application. Below are the fields as they appear in the administration interface, in the exact order:

  • Site Mode: A toggle/dropdown to switch the website status between Online and Offline.
    • Note: Ensure you copy the administrative password before putting the site in offline mode.
  • Password: The password required to access the site when in offline mode.
  • Website Title: The primary title of the platform, visible in browser tabs and metadata.
  • Censored Words: A field to list words restricted on the platform. Separate multiple words by commas.
  • Ban User with IP: A security field to block specific IP addresses from accessing the site. Separate multiple IPs by commas.
  • Google Language Translate API key: Input field for your Google Translate API key.
  • Do you want to allow adult content to view without enabling Adult content setting?: A preference toggle with options: No don't allow or Yes allow.
  • Do you want to restrict user to upload content without age verification?: A restriction toggle with options: No or Yes.
  • Maximum Upload Limit of Image: Set the maximum file size allowed for image uploads in MB. Enter "0" for unlimited.
  • Site CDN URL for internal files like css/js: The URL endpoint for your Content Delivery Network hosting internal style and script files.
  • Site Images CDN URL for external storage: The CDN URL used for images stored on external servers.
  • Site Videos CDN URL for external storage: The CDN URL used for video files stored on external servers.
  • TinyMce Editor API key: Input field for your unique TinyMCE API key to enable rich text editing.
  • Google Analytics Code: Input field for your Google Analytics tracking script or Profile ID.

3. Email Settings

Configuration for outgoing system emails and server details. Based strictly on the administration interface:

  • Contact Form Email: The email address where messages from the public "Contact Us" form are delivered.
  • From Name: The display name shown in the recipient's inbox for all automated platform emails.
  • From Address: The actual email address used to send outgoing communications.
  • Want to send welcome email to new signup users?: Toggle between Disabled and Enabled to control the automatic welcome message for new members.
  • Notify Admin by email when user signs up?: Toggle between Disabled and Enabled to receive administrative alerts for every new registration.
  • Select Logo to send in all Emails: A selection menu to choose the branding asset (e.g., logo.png) used in the header of email templates.
  • Email Types?: Select the transport method for sending emails. Options include:
    • SMTP: Standard protocol for sending emails via a mail server.
    • Gmail: Simple integration using a Google account.
    • Gmail Auth2: Secure integration using Google OAuth2 authentication.
    • SendGrid: Use the SendGrid API for high-deliverability transactional emails.
  • SMTP Username: The credential used for mail server authentication.
  • SMTP Password: The secure password for the chosen email transport method.
  • Use Secure Connection?: A toggle (No or Yes) to enable secure data transmission to the mail server.
  • Use TLS?: A toggle (No or Yes) specifically for enabling Transport Layer Security.

4. Social Login Settings

Manage authentication integrations with external social platforms. Below are the fields in the exact order they appear in the interface:

Facebook Login

  • Status: Toggle between Disabled and Enabled.
  • Help Link: Click here to learn how to create Facebook API key.
  • Facebook API ID: Your unique application identifier for Facebook integration.
  • Facebook App Secret: The private secret key for your Facebook application.

Google Login

  • Status: Toggle between Disabled and Enabled.
  • Help Link: Click here to learn how to create Google API key.
  • Google client ID: The public identifier for your application within the Google Cloud Console.
  • Google client secret: The private secret key used for Google authentication.

Twitter Login

  • Status: Toggle between Disabled and Enabled.
  • Help Link: Click here to learn how to create Twitter API key.
  • Twitter App Consumer Key: The API key provided by the Twitter/X Developer Portal.
  • Twitter App Consumer Secret: The private secret key for your Twitter/X application.

Apple Login

  • Status: Toggle between Disabled and Enabled.
  • Help Link: Click here to learn how to create Apple API keys.
  • Private key: Select the appropriate key file from the list:
    • birbtv-logo-dark-mode.png, movies.jpg, episodes.jpg, userPlan.png, favicon.png, logo.png, defaultMale.png, defaultBlog.png, defaultPlaylist.jpg, defaultVideo.png, defaultFemale.jpg, defaultCover.jpg
  • Download: Click here to Download it.
  • Apple Client ID: Your Services ID used for Apple authentication.
  • Apple Team ID: Your Apple Developer Team ID.
  • Apple Key ID: The specific identifier for your Apple authentication key.

6. Storage Settings

Configuration for file storage and content delivery.

  • Storage Type: Select your preferred storage provider. Available options include:
    • Local Storage (Recommended) Uses your local server as storage.
    • S3 Storage
    • Wasabi Storage
    • Digital Ocean
  • Connection Details: Note that upon selecting a storage provider, additional fields will dynamically appear to enter the specific credentials and configuration data required to establish a connection with that service.

7. Contact Us Settings

Configuration for public contact information and social media integration.

  • Google Map: Embed code or link for your Google Map location. Leave this field empty if you do not want a map displayed.
  • Contact Address: The physical mailing address of your platform or business.
  • Contact Phone Number: The primary telephone number for user support or inquiries.
  • Contact Fax Number: The fax number for official document transmissions.
  • Contact Email Address: The primary email address shown on the "Contact Us" page.
  • Facebook URL: Link to your platform's official Facebook page.
  • Twitter URL: Link to your platform's official Twitter/X profile.
  • Whatsapp URL: Direct link or number for WhatsApp business communication.
  • Linkedin URL: Link to your platform's official LinkedIn professional profile.
  • Pinterest URL: Link to your platform's official Pinterest page.

8. Newsletter Settings

Manage the platform's newsletter subscription functionality via Mailchimp integration.

  • Enable Newsletter Functionality: Toggle between Yes and No to enable or disable the newsletter system.
  • Help Link: Click to create Mailchimp API key.
  • Mailchimp API Key: Your unique API key obtained from your Mailchimp account settings.
  • Mailchimp List ID: The unique Audience/List ID where subscriber emails will be stored.
  • Newsletter Background Image: Select a background asset for the newsletter subscription section from the following list:
    • birbtv-logo-dark-mode.png, movies.jpg, episodes.jpg, userPlan.png, favicon.png, logo.png, defaultMale.png, defaultBlog.png, defaultPlaylist.jpg, defaultVideo.png, defaultFemale.jpg, defaultCover.jpg

9. Signup Settings

Manage the fields and requirements for the user registration form.

  • Do you want to enable Last Name on signup form?: Toggle between No and Yes to show/hide the Last Name field.
  • Do you want to enable Username on signup form?: Toggle between No and Yes to allow users to choose a custom username.
  • Do you want to enable Timezone on signup form?: Toggle between No and Yes to let users select their local timezone during registration.
  • Do you want to enable Phone Number on signup form?: Toggle between No and Yes to include a phone number input field.
  • Do you want to make Phone Number on signup required?: Toggle between No and Yes to make the phone number a mandatory field.
  • Do you want to enable Gender on signup form?: Toggle between No and Yes to include gender selection.
  • Do you want to enable Image Upload on signup form?: Toggle between No and Yes to allow users to upload a profile picture during signup.
  • Do you want to make Image Upload required on signup form?: Toggle between No and Yes to force users to upload an image before completing registration.
